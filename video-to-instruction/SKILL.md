# Инструкции по видео

По умолчанию выдай редактируемый DOCX. Сохрани деление исходников на части, если оно явно задано. Приоритет оформления у текущего образца пользователя. Для привычного оформления используй обновлённую ТР-7 как основной образец по [указателю примеров](references/examples.md).

1. Проверь доступ к записи. Для ссылки используй подходящий коннектор, для локального файла проверь путь. Извлеки звук через ffmpeg и распознай речь с таймкодами. Для русского языка можно использовать локальный faster-whisper с large-v3. Сверь команды, поля, статусы и результат по кадрам. При недоступности исходника сообщи, какой файл нужен.
2. Разложи материал по задачам пользователя. Для каждого сценария укажи исходные условия, путь в интерфейсе, действия и способ проверить результат. Различай ручные действия, автоматическое поведение системы и настройки демонстрационной базы. Убирай повторы и исправленные в ходе показа ошибки. Сохраняй ограничения и существенные исключения. Если порядок действий или название команды нельзя подтвердить, не достраивай его по догадке.
3. До сборки составь перечень значимых действий и результатов, затем сопоставь каждому пункту кадр и таймкод. Обязательно иллюстрируй открытие нужной формы, выбор команды, заполнение реквизитов, подтверждение и наблюдаемый результат. Если действие и результат видны на разных экранах, добавь отдельные кадры. Один кадр допустим, когда на нём ясно видны оба. Если запись не показывает нужный момент, укажи конкретный пробел при выдаче. Не ограничивай число рисунков или страниц заранее. Обрезай лишние панели, сохраняя необходимый контекст. Ставь тонкую красную рамку по внешней границе элемента с зазором до текста. Для плотных таблиц выделяй строку или группу целиком, либо указывай стрелкой со свободного поля. Наконечник доводи до края рамки, обходя подписи и значения. Проверь разметку на итоговом размере.
4. Для Word примени навык Documents. Помести основную часть инструкции в одну одноколоночную таблицу Word. В каждой строке держи нумерованный шаг, подпись и соответствующий кадр. Заголовок раздела размещай вместе с первым шагом. Подпись рисунка и изображение держи рядом с действием, таймкод добавляй, когда он помогает найти место в видео. При отсутствии отдельного образца опирайся на A4, Times New Roman и спокойную вёрстку сохранённых инструкций.
5. Отрисуй документ и проверь каждую страницу. Проверь по перечню, что у каждого значимого действия и наблюдаемого результата есть иллюстрация и что сценарий можно повторить по документу. Проверь одну колонку таблицы, читаемость, отсутствие перекрытий и соседство подписей с кадрами. Выдай итоговый DOCX и коротко сообщи о существенных расхождениях источника или принятых допущениях.
