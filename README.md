# Инструкции по видео

Навык Codex для подготовки пошаговых инструкций Word по видеодемонстрациям. В комплект входят восемь готовых образцов DOCX.

## Установка в Codex

Откройте Codex и отправьте запрос:

> Используй $skill-installer и установи навык из приватного репозитория Fregat-vrn/video-to-instruction по пути video-to-instruction. Для доступа используй мою авторизацию GitHub.

Для чтения репозитория нужна учётная запись GitHub с доступом к нему. После установки перезапустите Codex.

## Использование

> $video-to-instruction Сделай пошаговую инструкцию по этому видео.

Приложите запись или укажите ссылку на неё. Навык использует ffmpeg и faster-whisper для локальной обработки, когда они доступны.
