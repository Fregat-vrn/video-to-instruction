# Инструкции по видео

Вставьте в Codex одну строку:

```text
Установи навык https://github.com/Fregat-vrn/video-to-instruction/tree/main/video-to-instruction
```

Для установки нужен доступ к приватному репозиторию GitHub. После установки начните новый чат, приложите видео или ссылку и напишите:

```text
$video-to-instruction Сделай инструкцию по этому видео.
```

В комплект входят восемь образцов Word. Для локальной обработки записи используются ffmpeg и faster-whisper.
